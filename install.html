把好日子放到手機桌面

放好以後，在手機桌面點「好日子」就能打開，就像一般的 App。

  1. 用 Chrome 打開好日子的網址
    好日子行事曆的網址⋮
  2. 按右上角的「⋮」（三個點）
    好日子行事曆的網址⋮
  3. 按「加到主畫面」或「安裝應用程式」
    新增分頁
    書籤
    📲 加到主畫面
    設定
  4. 再按一次「安裝」或「新增」
    安裝
  5. 回到手機桌面，找到這個圖示
    好日子
  1. 用 Safari（藍色指南針）打開好日子的網址
    好日子行事曆的網址
  2. 按畫面下方中間的「分享」按鈕（方塊加向上箭頭）
    ‹›⬆︎📖⧉
  3. 往下滑，按「加入主畫面」
    拷貝
    加入書籤
    ⊞ 加入主畫面
  4. 按右上角的「新增」
    好日子新增
  5. 回到手機桌面，找到這個圖示
    好日子
找不到按鈕？ 每支手機的畫面可能有一點不同。請家人或志工幫忙，一次就好，之後都從桌面打開。
